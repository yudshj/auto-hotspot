# GitHub 开源图标参考

上游图形未改动；应用预览添加了自选底色和圆角底板，并调整了展示尺寸。尚未接入应用资源。

## 1. Tabler / Access Point

- 来源：https://github.com/tabler/tabler-icons/blob/main/icons/outline/access-point.svg
- 许可证：MIT，完整版权与许可见同目录 `tabler-LICENSE.txt`。
- 方向：对称、轻盈，最适合工具应用。

## 2. Phosphor / Broadcast · Duotone

- 来源：https://github.com/phosphor-icons/core/blob/main/assets/duotone/broadcast-duotone.svg
- 许可证：MIT，完整版权与许可见同目录 `phosphor-LICENSE.txt`。
- 方向：圆心与双层波纹，热点感更强。

## 3. Lucide / WiFi Sync

- 来源：https://github.com/lucide-icons/lucide/blob/main/icons/wifi-sync.svg
- 许可证：ISC，完整版权与许可见同目录 `lucide-LICENSE.txt`。
- 方向：循环箭头表达自动化，细节较多。

## 4. Phosphor / WiFi High · Fill

- 来源：https://github.com/phosphor-icons/core/blob/main/assets/fill/wifi-high-fill.svg
- 许可证：MIT，完整版权与许可见同目录 `phosphor-LICENSE.txt`。
- 方向：更醒目、更简洁，但功能感较弱。

MIT / ISC 均允许修改与分发，分发时需保留相关版权与许可声明。上游 main 分支可能更新；本目录保留了本次下载的原始 SVG。
